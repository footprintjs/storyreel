# choose-shape/ — the shape, in code

**Why:** a model choosing among all shapes costs a brief per run for a choice code can make from facts: the shapes the
drawer draws, the one the caller asked for, the points there are. `decide()` makes it, and a model is asked only when two
or more drawable shapes fit and the caller named none.

`FITS` (the least points each part needs) and `SHAPE_RULES` are data. Branches: `shape fits`, `shape asked`, `no shape`.

**Threats:** the rare shape brief carries shape descriptions and part counts only, no words of the conversation; the
answer must name a shape offered.
